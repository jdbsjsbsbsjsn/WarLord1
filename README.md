# جنگ‌سالار — نسخه ادغام‌شده

ساختار این خروجی:
- `index.html` — شامل HTML، تمام CSS و کد رابط کاربری (`ui.js`)
- `battle.js` — موتور نبرد
- `tutorial.js` — منطق آموزش

هر سه فایل باید در ریشهٔ مخزن GitHub قرار بگیرند.

## فایل‌های تکمیلیِ موجود در پروژهٔ اصلی
در ZIP ورودی، فایل `skins.js` وجود نداشت؛ بنابراین ارجاع آن در `index.html` حفظ شده و باید فایل اصلی `skins.js` را کنار `index.html` قرار بدهی.
همچنین فایل‌های سرور، تنظیمات بسته و دارایی‌های تصویری/صوتی در ZIP ورودی نبودند و در این خروجی ساخته یا جایگزین نشده‌اند.
