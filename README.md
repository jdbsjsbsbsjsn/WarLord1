# جنگ‌سالار — نسخهٔ چندفایلی

ساختار پروژه:

- `index.html` — ساختار صفحه و عناصر رابط
- `css/style.css` — تمام استایل‌های استخراج‌شده
- `js/battle.js` — موتور بازی، قوانین مبارزه، کمبوها و هوش مصنوعی
- `js/ui.js` — رابط کاربری، حساب/آنلاین، پروفایل، گرافیک و دانش‌نامه
- `js/tutorial.js` — منطق آموزش و مراحل تمرینی
- `skins.js` — فایل اسکین اصلی؛ باید کنار `index.html` قرار بگیرد

## اجرا و GitHub

تمام فایل‌ها و پوشه‌ها را با همین ساختار در یک مخزن GitHub قرار بده. برای GitHub Pages، در تنظیمات مخزن بخش **Pages** را روی شاخهٔ موردنظر و پوشهٔ ریشه تنظیم کن. سپس آدرس سایت را باز کن.

فایل‌ها را جداگانه جابه‌جا یا تغییرنام نده؛ مسیرهای نسبی داخل `index.html` به همین ساختار وابسته‌اند. فایل‌های تصویری/صوتی و `skins.js` مورد استفادهٔ نسخهٔ اصلی نیز باید در همان مسیرهای قبلی باقی بمانند.
